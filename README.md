## 📖 Sobre

Exemplos práticos de testes unitários com **Vitest** em TypeScript: de uma função de soma até um repositório de usuários em memória, cobrindo os casos de sucesso e de erro.

## 🎯 O que você vai aprender

- Configurar o Vitest em um projeto TypeScript
- Escrever testes com `test`, `it`, `describe` e `expect`
- Preparar o estado de cada teste com `beforeEach`
- Usar os matchers `toEqual`, `toHaveProperty`, `toHaveLength` e `toThrowError`
- Testar regras de negócio, como e-mail duplicado e usuário inexistente

## 🗂️ Estrutura

```
src/
├── entities/
│   └── user.ts
├── repositories/
│   ├── users-repository.ts
│   └── users-repository.test.ts
└── services/
    ├── sum.ts
    └── sum.test.ts
```

## 🚀 Como rodar

> Pré-requisito: [Node.js](https://nodejs.org/) 18+

```bash
# 1. Clone o repositório
git clone https://github.com/agustinhopneto/yt-unit-tests.git
cd yt-unit-tests

# 2. Instale as dependências
npm install

# 3. Rode os testes
npm test
```
