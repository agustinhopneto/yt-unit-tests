## 📖 About

Hands-on unit testing examples with **Vitest** in TypeScript: from a simple sum function to an in-memory users repository, covering both success and error cases.

## 🎯 What you’ll learn

- Set up Vitest in a TypeScript project
- Write tests with `test`, `it`, `describe` and `expect`
- Prepare each test’s state with `beforeEach`
- Use the `toEqual`, `toHaveProperty`, `toHaveLength` and `toThrowError` matchers
- Test business rules such as duplicated e-mails and missing users

## 🗂️ Structure

```
src/
├── entities/

├── repositories/
│   ├── users-repository.ts
│   └── users-repository.test.ts
└── services/
    ├── sum.ts
    └── sum.test.ts
```

## 🚀 Getting started

> Prerequisite: [Node.js](https://nodejs.org/) 18+

```bash
# 1. Clone the repository
git clone https://github.com/agustinhopneto/yt-unit-tests.git
cd yt-unit-tests

# 2. Install the dependencies
npm install

# 3. Run the tests
npm test
```
